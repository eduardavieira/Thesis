"Obtaining SWELL data" is a Matlab script for the Swell dataset based on these [scripts provided to read s00 files](https://easy.dans.knaw.nl/ui/datasets/id/easy-dataset:58624/tab/2). Labels (Neutral - N, Stressor Time Pressure -T, Stressor Interruptions - I) can also be found in the the file "SWELL-KW - overview available data.csv".

Wesad script based on this [repository](https://github.com/jaganjag/stress_affect_detection/blob/master/read_data.py). Labels are "baseline" and "stress".
